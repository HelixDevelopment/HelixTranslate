(B) Fresh-corpus rotation — a new recording run for a scope removes the agent’s OWN prior in-scope stale recordings FIRST (§11.4.107 not-stale + §11.4.86 roster-freshness); the agent’s own SAME-scope recordings ONLY, NEVER another project’s/operator-authored files (uncertain ⇒ surface, don’t delete §11.4.122/§9.2); committed docs/qa/<run-id>/ evidence (§11.4.83) is the durable record, NOT rotated. Classification: universal (§11.4.17). Composes §11.4.2/.5/.10/.83/.86/.107/.111/.122/.128/.137/.153/§9.2/.6. Canonical authority: constitution submodule Constitution.md §11.4.154.
